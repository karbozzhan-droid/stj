01 Бөлім

Теориялық негіздер

Жүйенің матрицалық түрі

Сызықтық алгебралық теңдеулер жүйесі (СТЖ) берілген болсын:
Ax = b немесе итерациялық түрге келтірілген түрі:
x = Bx + g. Мұндағы B — итерация матрицасы.

Жинақтылық шарты

Итерация процесі жинақты болуы үшін матрицаның нормасы 1-ден кіші болуы қажет:
||B|| < 1. Бұл диагностика диагональды басымдылық немесе бас диагональ элементтерінің үстемдігі арқылы қамтамасыз етіледі.

Алгоритм қадамдары

1. Бастапқы жақындашуды таңдау (x(0)).
2. Келесі итерацияны есептеу формулусы:
x(k+1) = Bx(k) + g.
3. Тоқтау шарты: ||x(k+1) - x(k)|| < ε.

02 Бөлім

Мысал есеп (Толық шешімімен)

Берілген жүйе:

10x₁ - 2x₂ - 2x₃ = 6

-x₁ + 10x₂ - 2x₃ = 7

-x₁ - x₁ + 10x₃ = 8 (немесе -x₁ - x₂ + 10x₃ = 8)

Итерациялық түрге келтіру (x = Bx + g):

x₁^(k+1) = 0.2x₂^(k) + 0.2x₃^(k) + 0.6

x₂^(k+1) = 0.1x₁^(k) + 0.2x₃^(k) + 0.7

x₃^(k+1) = 0.1x₁^(k) + 0.1x₂^(k) + 0.8

Есептеу қадамдары (ε = 0.001):

k (қадам) x₁^(k) x₂^(k) x₃^(k)
0 0.6000 0.7000 0.8000
1 0.9000 0.8600 0.9300
2 0.9580 0.9150 0.9760
3 0.9782 0.9334 0.9873
... Жинақталды 1.0000 1.0000 1.0000

04 Бөлім

C++ коды және Блок-схема

Алгоритм блок-схемасы

Жай итерация әдісінің логикалық құрылысы:

C++ Бағдарлама коды 

#iostream
#include <iostream>
#include <vector>
#include <cmath>

using namespace std;

int main() {
    int n = 3;
    double eps = 0.001;
    // Коэффициенттер матрицасы мен бос мүшелер
    vector<vector<double>> A = {
        {10, -2, -2},
        {-1, 10, -2},
        {-1, -1, 10}
    };
    vector<double> b = {6, 7, 8};
    vector<double> x(n, 0.0);
    vector<double> x_new(n, 0.0);
    
    int iter = 0;
    double diff;
    
    do {
        diff = 0.0;
        for (int i = 0; i < n; i++) {
            double sum = 0.0;
            for (int j = 0; j < n; j++) {
                if (i != j) sum += (A[i][j] / A[i][i]) * x[j];
            }
            x_new[i] = (b[i] / A[i][i]) - sum;
            diff = max(diff, fabs(x_new[i] - x[i]));
        }
        x = x_new;
        iter++;
    } while (diff > eps && iter < 100);
    
    cout << "Шешім " << iter << " қадамда табылды:\n";
    for (int i = 0; i < n; i++) {
        cout << "x" << i+1 << " = " << x[i] << endl;
    }
    return 0;
}
